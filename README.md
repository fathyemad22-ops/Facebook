# سيستم النشر التلقائي على صفحة فيسبوك 🤖📣

Claude بيكتب البوستات بالعامية المصرية ويعمل لها صور، وبينزلها على صفحتكم 4 مرات في اليوم، من غير ما حد يقعد على الجهاز.

```
 ┌───────────────┐    كل يوم    ┌─────────────────┐  4 مرات في اليوم ┌──────────────┐
 │  Claude بيكتب  │ ───────────▶ │ content/queue/  │ ───────────────▶ │ صفحة فيسبوك  │
 │  البوستات     │              │ (طابور البوستات) │  + صورة كارت      │              │
 └───────────────┘              └─────────────────┘                  └──────────────┘
                                       ▲  تقدروا تراجعوا وتعدلوا أي بوست قبل ما ينزل
```

**أول بوستات جاهزة:** فيه 14 بوست مكتوبين ومعاهم صورهم في `content/queue/`. يعني أول ما تربطوا الصفحة، النشر يبدأ على طول.

---

## ⭐ أسهل طريقة: اربطوا الصفحة بـ Claude عن طريق Zapier (من غير أي برمجة)
1. في **claude.ai ← Settings ← Connectors**، اربطوا **Zapier**.
2. جوه Zapier، زوّدوا تطبيق **Facebook Pages**، وسجّلوا دخول بحساب فيسبوك اللي أدمن على الصفحة، واختاروا الصفحة. وفعّلوا الأكشن اللي اسمه **Create Page Photo**، وكمان **Create Page Post**.
3. قولوا لـ Claude «خلاص ربطت»، وهو هينزل أول بوست بنفسه ويظبط إن البوستات تنزل لوحدها 4 مرات في اليوم.

> Zapier ممكن يحتاج اشتراك مدفوع لو عدد البوستات كبير. الطريقة التانية تحت مجانية، بس محتاجة خطوات أكتر مرة واحدة بس.

## إحنا هنشتغل على إيه؟ (الفكرة المقترحة)

### 🌟 «AI بالمصري»: الذكاء الاصطناعي ببساطة
صفحة بتعلّم الناس العادية يستخدموا ChatGPT وClaude وGemini في شغلهم ودراستهم وحياتهم، بالعامية ومن غير تعقيد.

**ليه دي فكرة كويسة؟**
- **الطلب عليها كبير وبيزيد:** كل الناس سمعت عن الـ AI، ومعظمهم مش عارفين يستفيدوا منه.
- **المحتوى العربي المفيد فيها قليل:** أغلب الموجود يا إنجليزي يا أخبار وتهويل.
- **محتوى بيعيش:** إحنا بنعلّم مهارات (برومبتات ونصايح)، مش أخبار بتقدم بعد أسبوع.
- **الناس بتحفظه وبتشاركه:** البرومبتات الجاهزة من أكتر البوستات اللي الناس بتعملها حفظ ومشاركة.
- **له طرق ربح واضحة:** Facebook Content Monetization، ورعاية، وكورسات أو ملفات برومبتات بعدين.

**أنواع البوستات** (بتتوزع تلقائي): برومبت جاهز، نصيحة عملية، خرافة ولا حقيقة، يعني إيه، استخدمه في (مهنة معينة)، سؤال للمتابعين.

### أفكار تانية جاهزة (بتتغير بسطر واحد في `config.yaml`)
| `niche` | الفكرة |
|---|---|
| `tech_ai` | **AI بالمصري** (الافتراضي) |
| `money` | **فلوسك:** إدارة مالية شخصية وتوفير |
| `knowledge` | **معلومة على الماشي:** ثقافة عامة ومعلومات غريبة |
| `small_business` | **مشروعك الصغير:** تسويق وبيع أونلاين لأصحاب المشاريع |

وتقدروا تعملوا فكرة جديدة خالص: انسخوا أي ملف من `niches/` وعدّلوه.

## الطريقة التانية: GitHub Actions لوحده (مجانية، حوالي 30 دقيقة مرة واحدة)

### 1) تطبيق ميتا وتوكن الصفحة
محتاجين حاجتين: **رقم الصفحة (Page ID)** و**توكن الصفحة (Page Access Token)**.

1. ادخلوا [developers.facebook.com](https://developers.facebook.com) بنفس الأكونت اللي أدمن على الصفحة، ودوسوا **My Apps ← Create App**.
2. اختاروا الاستخدام اللي بيدير الصفحات (اسمه حالياً **Manage everything on your Page**)، وكمّلوا لحد ما التطبيق يتعمل.
3. افتحوا [Graph API Explorer](https://developers.facebook.com/tools/explorer):
   - اختاروا التطبيق بتاعكم من فوق.
   - من **Permissions** زوّدوا: `pages_show_list` و`pages_read_engagement` و`pages_manage_posts`.
   - دوسوا **Generate Access Token**، ووافقوا، واختاروا الصفحة.
4. **خلّوا التوكن دايم:**
   - دوسوا على علامة ⓘ جنب التوكن، وبعدين **Open in Access Token Tool**، وبعدين **Extend Access Token**، وانسخوا التوكن الجديد.
   - ارجعوا للـ Explorer، وحطوا التوكن الجديد، ونفذوا الطلب ده: `me/accounts?fields=id,name,access_token`
   - هيظهرلكم `id` الصفحة (ده **FB_PAGE_ID**) و`access_token` (ده **FB_PAGE_ACCESS_TOKEN**). توكن الصفحة اللي جاي من توكن طويل المدى **مالوش تاريخ انتهاء**.
   - أو بأمر واحد من الجهاز: `python -m fbposter token --app-id ... --app-secret ... --user-token ...`
5. **مهم:** حوّلوا التطبيق لوضع **Live** من لوحة التطبيق. هيطلب منكم رابط سياسة خصوصية، وتقدروا تنشروا [PRIVACY_POLICY.md](PRIVACY_POLICY.md) في أي صفحة عامة وتحطوا الرابط. التطبيق وهو في وضع التطوير ممكن البوستات اللي بينشرها ماتظهرش غير ليكم إنتم.

> بما إنكم أدمن على التطبيق والصفحة، الصلاحيات دي بتشتغل من غير مراجعة من ميتا (App Review).

### 2) مفتاح Claude (عشان يكتب البوستات كل أسبوع لوحده)
من [console.anthropic.com](https://console.anthropic.com): اعملوا **API Key** واشحنوا رصيد.
التكلفة بتقريب: كتابة 14 بوست في الأسبوع حوالي سنتات قليلة لحد أقل من دولار، على حسب الموديل والـ effort.
مش عايزين API؟ شوفوا [طرق ملء الطابور](#طرق-ملء-الطابور) تحت.

### 3) السيكرتس على GitHub
في الريبو: **Settings ← Secrets and variables ← Actions ← New repository secret**

| الاسم | القيمة |
|---|---|
| `FB_PAGE_ID` | رقم الصفحة |
| `FB_PAGE_ACCESS_TOKEN` | توكن الصفحة |
| `ANTHROPIC_API_KEY` | مفتاح Claude (اختياري) |

⚠️ ماتحطوش التوكنات دي في أي ملف في الريبو أبداً.

### 4) جرّبوا
1. **Actions ← Publish post ← Run workflow**، وعلّموا على **Dry run** عشان تشوفوا البوست من غير ما ينزل.
2. لو تمام، شغّلوه تاني من غير Dry run، وأول بوست هينزل على الصفحة ✅
3. بعد كده بينزل لوحده **4 مرات في اليوم: 9 الصبح، و1 الضهر، و6 المغرب، و10 بالليل بتوقيت القاهرة** (كل ميعاد بيتأخر ساعة في التوقيت الصيفي).

> المواعيد التلقائية (schedule) في GitHub بتشتغل بس من **الفرع الأساسي (default branch)** للريبو. لو الشغل ده على فرع تاني، اعملوا merge للفرع الأساسي.

## التحكم اليومي

- **تشوفوا اللي هينزل:** افتحوا `content/queue/` على GitHub. كل بوست ملف JSON، وبيتنشروا بالترتيب.
- **تعدّلوا بوست:** عدّلوا `text` في ملفه. ولو عايزين تغيّروا الصورة، امسحوا ملف الـ `.png` اللي بنفس الاسم، وهتتعمل صورة جديدة وقت النشر.
- **تلغوا بوست:** امسحوا ملفه.
- **وضع الموافقة:** خلّوا `require_approval: true` في `config.yaml`، ومفيش بوست هينزل غير لما تكتبوا في ملفه `"approved": true`.
- **تأجيل بوست لميعاد معين:** زوّدوا في ملفه مثلاً `"not_before": "2026-12-01T18:00:00+02:00"`.
- **تغيير المواعيد أو عدد البوستات في اليوم:** في `.github/workflows/post.yml`. زوّدوا أو شيلوا ساعات من السطر `cron`. التوقيت هناك UTC، والقاهرة بتبقى UTC+2 في الشتا وUTC+3 في الصيف.
- **تغيير اسم الصفحة أو الألوان أو الفكرة:** من `config.yaml`.
- **البوستات اللي نزلت:** متسجلة في `content/history.jsonl`، ومعاها رابط كل بوست.

## طرق ملء الطابور
1. **تلقائي بـ Claude API:** كل يوم الـ workflow اللي اسمه **Write new posts** بيكمّل الطابور لحد 28 بوست (يعني أسبوع). وتقدروا تشغّلوه يدوي في أي وقت.
2. **من Claude Code من غير API:** قولولي في أي جلسة «اكتب بوستات الأسبوع الجاي» وأنا هكتبها وأرفعها على الطابور. وممكن كمان نظبط مهمة مجدولة تعمل كده كل أسبوع.
3. **يدوي:** اكتبوا ملف JSON فيه البوستات ونفذوا `python -m fbposter add posts.json`.

لو الطابور فضي ومفيش مفتاح API، النشر بيقف ويظهر تحذير في Actions، ومفيش أي حاجة بتبوظ.

## أوامر للجهاز (اختياري)

```bash
pip install -r requirements.txt
cp .env.example .env              # وحطوا القيم فيه
python -m fbposter check          # يتأكد من الإعدادات والتوكن
python -m fbposter status         # الطابور فيه كام بوست وإيه اللي جاي
python -m fbposter preview        # يعرض البوستات ويعمل صورها
python -m fbposter plan --count 7 # Claude يكتب 7 بوستات جديدة
python -m fbposter post --dry-run # يوريكم البوست الجاي من غير ما ينشره
python -m fbposter post           # ينشر البوست الجاي فعلاً
```

## مشاكل شائعة
| المشكلة | الحل |
|---|---|
| `Token problem` / كود 190 | التوكن انتهى أو اتلغى، لأن الباسورد اتغير مثلاً. اعملوا توكن جديد (خطوة 1) وحدّثوا السيكرت. |
| البوستات ظاهرة ليكم بس | التطبيق لسه في وضع التطوير. حوّلوه لـ Live (خطوة 1 رقم 5). |
| `Nothing to publish` | الطابور فاضي. شغّلوا **Write new posts** أو زوّدوا بوستات. |
| الحروف العربي مقطعة في الصورة | محتاجين مكتبة `libfribidi0`، وهي بتتسطب تلقائي في GitHub Actions. |
| الـ workflow فشل وهو بيعمل push | Settings ← Actions ← General ← Workflow permissions ← Read and write. |

## نصايح عشان الصفحة تكبر 📈
- **الانتظام أهم من الكترة:** 3 لـ 5 بوستات في اليوم بانتظام أحسن من عشرة مرة واحدة وبعدين سكوت. ولو زوّدتوا عن كده جامد، وصول كل بوست لوحده ممكن يقل.
- **ردّوا على الكومنتات في أول ساعة:** ده بيرفع وصول البوست جامد.
- **ثبّتوا (Pin) أحسن بوست برومبت** في أول الصفحة.
- **راقبوا الأرقام** من Meta Business Suite، وزوّدوا وزن النوع اللي بيجيب تفاعل أكتر (`weight` في ملف الـ niche).
- بعد كام أسبوع، حوّلوا أنجح البوستات لـ Reels قصيرة.
